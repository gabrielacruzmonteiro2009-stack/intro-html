Sobre formúlarios

O que são formúlarios?

Os formúlaros são uma das partes mais importantes do nosso HTML semântico. Ele serve para:

  • Entrada de dados
  • Interação
  • Acessibilidade
  • Validação e envio de informações

Como trabalhar com um form no HTML

Para comerçamos a trabalhar com um formúlario dentro do HTML, utilizamos o elemento < form >

Esse elemento, representa um formúlario interativo.
