Entendendo os atributos

  • src: Source/fonte: É o caminho onde a imagem está armazenada. Pode ser um caminho local ou uma URL.
  • alt: alt/alternative: É uma breve descrição da imagem. É crucial para Acessibilidade e como fallback caso a imagem não seja carregada (plano B).

    Sobre tipos de imagens

    Você pode encontrar um acervo muito grande de tipos de imagens. A escolha da imagem certa pode elevar a performance do seu site. Veja a lista abaixo:

    • JPEG/JPG: Bom para fotografias, produtos fotografados, imagens com muitos detalhes e cores. Se você tentar otimizar demais, a perda de qualidade se torna visível.
    • PNG: Suporta transparência e é muito bom para imagens que precisam preservar certos detalhes, como logotipos, ícones e gráficos. Imagens que precisam suportar transparência e etc.
    • WEBP: Formato recente desenvolvido com foco na web. Além de também suportar transparência, também consegue trabalhar com imagens sem alta definição. Excelente escolha para fotografias, imagens grandes de produtos, imagens com transparência e imagens gerais.
    • AVIF: É um formato mais recente e também muito eficiente. É excelente, para fotografias, imagens grandes e sites onde o desempenho e economia de dados são extremamentes importantes.
    • SVG: É um elemento vetorial, excelente para logos, ícones e etc.
