Sobre elementos de Listas

Listas são elementos que permitem organizar informações de forma hierárquica HTML.

Conhecendo as listas

Listas não ordenadas (UL)

A lista não ordenada é utilizada para exibir itens em uma sequência que não tem uma ordem específica.

  • Morango
  • Maracujá
  • Uva
  • Banana

Listas ordenadas (OL)

A lista ordenada é utilizada para exibir itens em uma sequência que tem uma ordem específica.

  1. Primeiro a Farinha de trigo
  2. Segundo os Ovos
  3. Terceiro o Leite
  4. Quarto o Chocolate em pó
